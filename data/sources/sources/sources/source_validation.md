# Source Validation

This document records the source-screening process used to select the final dataset for the project.

## Selection Criteria

The dataset had to satisfy the following conditions:

- 2025 must be an Actual or Base Year
- 2026F and 2027F must come from the same institution
- Global / Worldwide coverage
- Annual values must be available
- CAGR must be at least 15%
- Publicly verifiable source
- The indicator must reasonably represent increasing subsea power cable demand

## Why This Dataset Was Selected

The final dataset was selected because it satisfies the main research conditions:

- 2025 is explicitly treated as the Base Year
- 2026 and 2027 are forecast values from the same source
- Global / Worldwide market coverage
- Annual values are publicly available
- CAGR exceeds 15%
- The Offshore Wind Cable market is directly linked to subsea power cable demand

## Important Limitation

This dataset does **not** represent the entire global subsea power cable market.

It represents the **global Offshore Wind Cable market**, including cable demand associated with offshore wind projects.

Therefore, in this project it is used as a **proxy indicator for subsea power cable demand growth**, not as a complete measure of the total subsea power cable market.

## Supporting Sources

### TGS | 4C

### Spinergie
Used to cross-check offshore power cable demand growth and installation-market trends.

## Research Note

AI-assisted research was used to identify candidate sources and compare dataset structures.

However, candidate datasets were not accepted solely based on AI-generated summaries. Each dataset was screened based on:

- source consistency
- year classification
- geographic scope
- CAGR
- availability of annual values
- market-definition differences

This validation process was used to reduce the risk of mixing historical values with outdated forecasts or using incompatible market definitions.
